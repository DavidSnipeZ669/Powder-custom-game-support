# Call of Duty: Modern Warfare 2 (2022) - Powder Custom Game Support

## 🎮 Game Overview

**Title:** Call of Duty: Modern Warfare II (2022)
**Genre:** Military FPS
**Developer:** Infinity Ward
**Release Year:** 2022
**Platform:** PC, PlayStation, Xbox

Call of Duty: Modern Warfare II (2022) is the sequel to the 2019 reboot and features enhanced graphics, new gameplay mechanics, and a comprehensive multiplayer experience. This Powder configuration provides OCR-based event detection for the game.

## 📋 Features

### ✅ Implemented Features
- **18+ Event Types** - Comprehensive combat and multiplayer events
- **Multi-Region OCR** - 4 optimized detection zones
- **Performance Optimized** - Balanced for accuracy and performance
- **Game Mode Support** - Multiplayer, Ranked, Ground War
- **Context-Aware Processing** - Intelligent event classification

**Combat Events:**
- `kill` - Basic enemy elimination
- `headshot` - Headshot kills
- `meleeKill` - Melee eliminations

**Multi-kill Events:**
- `doubleKill` - 2 quick eliminations
